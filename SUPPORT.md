# Support and contributions

Issues and pull requests are welcome. This project is maintained on a best-effort
basis: response times, acceptance of contributions and future releases are not
guaranteed. A source checkout is not required to report a problem.

Include the version/package filename, OS version, architecture, RAM, display
scale, active mode/map source and whether 3D, Offline mode or a VM was active.
For protocol issues include transport/rate and the TCP Server/Client roles.
Give short reproduction steps, expected/actual results, elapsed running time
and relevant Performance Monitor readings.

Never attach unredacted configuration exports, API keys, client secrets, internal
routes, equipment details or complete packet captures. Review logs/screenshots
first. Follow `SECURITY.md` for vulnerabilities; do not post exploit details in
a public issue. Contributor guidance is in `CONTRIBUTING.md`.

Check one mode/output first, compare Output Monitor with an independent receiver,
and verify installed water coverage before enabling Avoid Land offline. A sent
counter is not a receiver delivery acknowledgement.

Optional support: [Maritime Knowledge Bites](https://mybook.to/MaritimeKnowledgeBites).
Buying the book does not unlock features and is not a requirement for use.
