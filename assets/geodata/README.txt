OpenStreetMap simplified coastline land polygons
================================================

The bundled archive was downloaded from:
https://osmdata.openstreetmap.de/data/land-polygons.html

It contains simplified coastline land polygons in Web Mercator (EPSG:3857)
for offline land/water classification. Inland water is refined at runtime from
small, cached OpenStreetMap map tiles when needed.

The data is Copyright OpenStreetMap contributors and is available under the
Open Database License (ODbL):
